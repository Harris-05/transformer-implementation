# Upload and submit

Repository: https://github.com/Harris-05/transformer-implementation  
Recorded demo: https://youtu.be/-zL3ECuJL1A

The source/results archive under `submission/` is prepared for a new assignment
repository. It excludes large adapter/base weights, local environments and caches.
The complete submission archive additionally includes the original selected
adapter/results ZIP. Do not upload the large weights ZIP as an ordinary GitHub file.

## GitHub

1. Create your assignment repository in GitHub.
2. Extract `i232535_Assignment2_Source.zip` into a **new dedicated folder**. Do not
   initialize or push the enclosing home-directory repository accidentally.
3. Upload those files or initialize version control in that new folder and push
   to the intended repository. Include `report/`, `results/`, `configs/`, source,
   dependency files, split manifest, README and demo instructions.
4. Upload `finetuning_results.zip` to Google Drive, a Hugging Face model repository,
   or another reachable file host. Provide a real download link and test access
   while signed out. The selected adapter SHA256 is recorded in its summary.
5. Add repository, adapter and video URLs to `SUBMISSION_CHECKLIST.md` and the
   assignment submission. Do not leave the URL placeholders as if completed.

No repository or public file has been created automatically: the destination,
account and sharing choice belong to you. No made-up URLs are included.

## Classroom submission

- `report/TrialScreen_Report.pdf` (IEEE paper).
- GitHub source URL and LaTeX source project link.
- Adapter weights or working download link.
- Fixed split manifest and raw evaluation/benchmark logs (inside source archive).
- Reproducibility/startup instructions (README and APPLICATION.md).
- Five-to-seven-minute recorded browser demo URL; use DEMO_AND_DEFENSE.md.

The complete local archive is a convenience for transferring the prepared files;
it does not replace required repository/video/download links or attendance at the
live demo. Final held-out metrics are verified; do not perform additional tuning
after inspecting them.
