# Local interface fonts

Instrument Sans and Instrument Serif are supplied through Google Fonts and are
licensed under the SIL Open Font License 1.1. Local TrueType assets keep the
application independent of third-party browser requests.

- Instrument Sans: https://github.com/google/fonts/tree/main/ofl/instrumentsans
- Instrument Serif: https://github.com/google/fonts/tree/main/ofl/instrumentserif
- License: https://openfontlicense.org/open-font-license-official-text/

The original font copyright and name records remain embedded in the font files.
